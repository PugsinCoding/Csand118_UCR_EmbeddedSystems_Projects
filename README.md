<h2>LABS</h2>
<h3>Lab 1: Binary Addition LED</h3>
<p>Two-Button input and 4 LEDs. Programmed using bit manipulation through bitwise shifting and logical operators to create a system where the left button adds in binary from 0 to 15 and right button from 15 to 0. The 4 bit addition and subtraction is represented through the LEDs.</p>
<p>Created boundary conditions to prevent overflow and tested through simulation and physical model that the circuit and program has no issues</p>
